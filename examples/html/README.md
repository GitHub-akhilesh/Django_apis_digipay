# DigiPay Chat SDK — Plain HTML / Web Component Starter Example

1-line script embed for legacy HTML, PHP, Django, JSP, and Static sites using `<digipay-chat>` Web Component.

## Quickstart

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>DigiPay Web Portal</title>
  
  <!-- Load SDK & Widget Assets -->
  <script src="https://cdn.digipay.com/sdk/digipay-chat-sdk.js"></script>
  <script src="https://cdn.digipay.com/sdk/digipay-chat-widget.js"></script>
</head>
<body>
  <h1>Welcome to DigiPay Admin Portal</h1>

  <!-- Floating Chat Assistant -->
  <digipay-chat csc-id="500100100014" mode="floating" theme="dark"></digipay-chat>
</body>
</html>
```
